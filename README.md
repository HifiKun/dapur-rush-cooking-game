Dapur Rush is a fast-paced 2D cooking game set in an Indonesian warung: take orders from the board, cook chicken and eggs on the stove, assemble dishes on the serving plate, and serve them before their patience runs out.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser and play with keyboard and mouse.
